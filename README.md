# lib_webview

## English (United States)

Fork of [desktop-app/lib_webview][upstream], used by [fortsoft-eu/tdesktop][parent]:
Telegram Desktop 7.1.3 with a Windows 2000-style GUI.

Embedded browser integration and dialogs. Local changes align dialog
button spacing and sizing with the Windows 2000-style interface and make
the disabled defaults for inspection and legacy Edge explicit.

Build this library as part of the parent project, not as a standalone application.
